# Upload screenshots — no JSON or coding needed

1. Open the folder for your project on GitHub.
2. Choose **Add file → Upload files**.
3. Drag in your PNG, JPG, WebP, GIF or AVIF screenshots.
4. Click **Commit changes**.

The site's build automatically discovers the images and adds them to the project's Gallery tab. Image captions are derived from filenames (e.g. `packet-inspector.webp` becomes “Packet Inspector”). You do not need to create or edit any JSON file.

For a project folder that does not yet exist, GitHub needs it created once. After that, all future updates are image uploads only.

Please remove private credentials, personal data, internal IPs, sensitive chats and unredacted incident evidence from public screenshots.
